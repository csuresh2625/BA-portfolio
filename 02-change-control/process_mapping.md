# As-is and to-be process maps (conceptual)

**As-is (simulated):** Client/site request → email clarification → ad hoc cost estimate → approval chase → update plan → manual status tracking.

**To-be (proposed):** Standard intake form → unique ID and classification → impact/estimate review → routed approval with SLA alerts → decision log → change implementation → cost variance review → dashboard.

**Gap:** No single request register, standard ownership or aging alert. **UAT focus:** status transitions, mandatory data, escalation rules and auditability.
