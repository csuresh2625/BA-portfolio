Approach

Define the problem → identify stakeholders and process gaps → specify measurable requirements → analyse sample data → write user stories and UAT → propose improvements and validation steps.

Methods: Requirements documentation, stakeholder coordination, process mapping, gap analysis, user stories, acceptance criteria, UAT design, SQL, Excel and Power BI training.

Transparency: The case studies are educational simulations. Recommendations are proposals, not delivered business outcomes.

Reproduce the work

Download the portfolio package and run python rebuild_and_verify.py from the portfolio folder. Each project includes CSV data, SQLite queries, a requirements document, user stories, UAT test cases and process mapping.
